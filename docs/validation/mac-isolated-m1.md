# Mac 隔离验证记录：第一阶段实现

日期：2026-11-01。状态：M0 的 Mac 准备完成；M1 的内核往返验证通过，M1 整体尚未通过。软件尚无可安装候选版，未接入 R2。

## 实际完成的实现

- `tools/codex_lab/inventory.py`：只读聚合 rollout 头部信息，区分桌面、CLI、IDE、子会话和未知来源，报告不可读条目，不输出会话正文、路径或账户标识。
- `safety.py`、`client.py`：专用临时目录、受限环境、原生 JSON-RPC 客户端、请求超时、拒绝权限申请和测试实例互斥。
- `bundle.py`：仅面向合成数据的原样导出、SHA-256 校验、按原生日期布局导入、重复导入去重、前缀版本推进、分歧拒绝覆盖、修改前备份和备份恢复。
- `fixture_provider.py`：本机固定响应服务，不连接真实模型、不消耗账号额度、不读取登录凭据。所有对话均由安装在 Mac 上的 Codex 内核真实生成和持久化。
- `verify_native.py`：可重复执行的分页、迁移、环境说明、实际目录、往返、恢复、归档检查。
- `verify_boundary.py`：验证进程确实不能写入测试目录外的哨兵文件、不能读取日常 Codex 目录、只能连接指定回环端口。

这些工具是研究工具，不能导入日常 Codex 数据。产品技术栈尚未变更或最终定案。

五组往返均从 3 个持久化轮次开始（两轮消息含图片，加一次实际命令），B 续写后为 5 轮，A 接回再续写后为 7 轮。分页大小设为 1，逐页检查，避免只验证首屏。

每组验证：

1. 原样保留 rollout 字节和嵌入图片，迁移前后的消息、工具结果及轮次内容一致。
2. B 与返回 A 均通过原生 `thread/shellCommand` 执行 `pwd` 与读取各自的验证文件；核对持久化命令输出，不只检查声明的目录。
3. B 的下一次请求仍包含仅在最早轮次出现的随机标记，并包含目标设备环境说明。
4. 重启后 B 的目录保持正确，重复导入不产生重复对话。
5. 恢复备份后由原生内核读取原历史并继续，随后形成的独立分歧不会被另一版本覆盖。
6. 显式维持 read-only 与 on-request；研究客户端拒绝权限申请。`thread/shellCommand` 本身属于用户显式命令接口，其外围仍受测试系统限制，此项不等于验证所有 agent 工具权限行为。

## 本轮发现与实现影响

- 当前三个版本支持在隔离目录中从原样 rollout 恢复测试会话，未删除数据库，也未复制源设备数据库。此证据只覆盖测试内容，不能泛化到所有真实会话、子会话、附件和未来版本。
- 目标文件必须符合原生目录和文件名布局；仅放在 sessions 根目录不能保证被枚举。
- 0.166 的历史响应增加了 item 的 `startedAtMs`、`completedAtMs`，0.164 的响应不暴露这两个字段。跨版本显示内容比较只归一化这两项；迁移包仍保留全部原始字节，不删除源时间信息。
- 本次试验中，仅传入 `thread/resume.developerInstructions` 未使目标环境说明进入下一轮请求。显式 `thread/inject_items` 可实现；未来生产流程需在用户触发继续时使用，避免同步自动发送任务，并记录映射身份以免重复注入。
- 新导入的归档会话可出现在列表，但历史投影为空。隔离试验通过原生取消归档、恢复加载、重新归档建立历史投影，最终归档状态保持不变。生产实现仍需为这一多步过程补充任务日志和中断恢复，不能只报告文件下载成功。
- 原生 schema 中存在的 `thread/items/list` 在当前桌面内核返回未支持；本轮使用 `thread/turns/list`、`itemsView=full` 和分页获取内容。

## 尚未通过的关卡

- 三个实际用户入口的界面可见性与打开行为（本轮调用各入口随附的 app-server，不等于实际 Desktop、CLI TUI、VS Code 界面验收）。
- 真实模型基于历史进行推理的验收；本轮只证明送入模型的上下文和原生执行行为，响应由本机固定服务产生。
- 外部附件、子会话依赖、项目元数据、未支持历史版本及完整资源清单。
- 多目标界面与各入口状态、共享数据写入协调、用户凭据管理、生产同步协议与加密。
- R2、Linux、Windows、安装包和中英文界面。

## 开发者复现

仅使用 Python 标准库。普通检查：

```sh
python3 -m unittest discover -s tests -v
```

在允许建立 macOS 进程限制的开发终端中运行（如果外层限制阻止建立隔离，工具应失败，不能移除隔离后重试）：

```sh
python3 -m tools.codex_lab.verify_boundary
python3 -m tools.codex_lab.verify_native \
  --desktop /path/to/desktop/codex \
  --cli /path/to/cli/codex \
  --ide /path/to/vscode-extension/codex
```

每次运行新建 `sesshuttle-lab-*` 临时目录，保存合成数据、备份和报告，不复制真实历史，不自动清理旧历史。仅重验归档可加 `--archive-only`。测试不是最终用户的使用步骤。
