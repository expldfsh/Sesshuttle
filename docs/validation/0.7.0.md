## 待用户验收

开发环境没有 Arch 虚拟机、真实 R2 或可用的 Linux 系统密码库，以下项目需在真实环境确认：

1. **Mac ↔ Arch 真实换机往返**：两端安装 0.7.0 包，Mac 上传 → Arch 导入并在 GPT 桌面端继续 → Arch 上传 → Mac 导入并继续（[Linux 验收清单](../guides/zh-CN/linux-acceptance.md)）。
2. **真实 R2**：用自己的 Bucket 创建同步空间、导出连接文件、在另一台电脑导入并加入。
3. **Linux 系统密码库授权**：「记住连接…」「解锁并连接…」以及取消后仅本次可用的路径。
4. **`scripts/cross-device.mjs` 的 Arch 端**（receive），以及 `scripts/verify-import-window.mjs` 在安装包上、用提供模型服务目录的 Codex 程序运行“补齐服务后重试”一段。
5. **在真实 GPT 桌面端继续对话**：导入后对话出现在所选项目下，旧消息可见，新一轮能保留。
6. `.deb` 在 Debian / Ubuntu 上安装启动（开发中只构建、未安装）。
