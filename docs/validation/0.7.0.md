## 原生 Codex 往返

在 Apple Silicon Mac 上用 Homebrew 的 Codex `0.166.0`（两端同版本），在临时 Lab 中运行移植为 JS 后的验收脚本：

| 脚本 | 结果 |
| --- | --- |
| `scripts/roundtrip.mjs` | A 3 轮 → B 续写到 5 轮 → A 续写到 7 轮，两端读回早期上下文并验证工作目录，与移植前的 Python 版本结果一致 |
| `roundtrip.mjs` 变体 | 压缩历史、仅数据库记录（导入在写入前拒绝）、目标端原生项目、目标端重复身份均通过 |
| `scripts/missing-image-roundtrip.mjs` | 确认缺图后 B 端只替换该图片输入，文字与工具历史不变，A/B 均可续聊；`--compressed` 通过 |
| `scripts/real-copy-roundtrip.mjs` | 使用 Lab 中以 `openai` 提供方生成的合成来源：数据库条目逐项保留，续聊 2 → 3 轮 |
| `scripts/cross-device.mjs` | 在同一台 Mac 上依次执行 source / receive / return 通过；真实 Mac ↔ Arch 待用户验收 |
| `scripts/check-runtime.mjs` | ChatGPT 桌面端自带的 Codex `0.167.0-alpha.3.2`（`CodexCLI.app/Contents/MacOS/codex`）快速验证约 0.7 秒通过，项目接口可用 |
| `scripts/verify-import-window.mjs` | 开发构建、测试模式下中英文 first / reopen 均通过：三步导入、路径检测、快速验证取消后重试；该 Codex 版本不提供模型服务目录，“补齐服务后重试”一段需在 Arch 上验收 |

## 界面走查

`scripts/ui-walkthrough.mjs` 在测试模式下逐页走查中英文、1320×860 与 780×600 两种窗口（共 100 张截图，未提交）：对话、首次使用清单、上传两步、导入三步、删除两步、任务面板、项目与应用、同步记录、备份三个标签页、设置（未连接 / 已连接）、诊断和错误示例。无水平滚动、顶栏遮挡、原始键名或不可见焦点；64 次打开页面、弹窗、详情和标签页的记录中，只有读取本机已保存状态和 `stat` 的请求，模拟 S3 请求数为 0。
