# 0.8.0 本机数据文件夹验收

本轮交付 Apple Silicon Mac 与 x86_64 Linux。用户首次选择父目录并核对完整路径。设置、备份、回收站和临时文件随专用文件夹管理。既有配置和旧凭据完成独立校验后，可以从设置核对并清理旧位置。当前为本地验收包。

## 数据保护

- 迁移使用 SQLite 在线备份，核对数据库完整性、所有键值和设备标识。备份、回收站、恢复文件和启动脚本逐文件校验，CLI 启动脚本保留可执行权限。只在完整副本可读时启用新位置。
- 上一版保存的 macOS 钥匙串条目、Linux Secret Service 条目或系统加密文件按原安装标识读取。用本地密码加密、重新解密并核对后才允许清理。清理前再次比较系统条目；取消授权保留旧数据库。
- 用户回看新位置后，确认窗口列出原目录及待清理内容。源数据变化、新位置副本损坏、路径包含不安全链接时，清理停止。原目录里其他文件会保留并提示路径。
- 同一登录会话只运行一个实例。测试使用临时合成 Codex 数据、模拟 S3 和隔离的系统密钥服务。

## 用户验收

1. 退出旧版，从应用图标首次启动。可先取消，再启动、选位置，核对显示的完整路径。
2. 有旧版时选择迁移。查看设置、设备名、备份和回收站。有已保存的连接时，先迁移凭据，再关闭并重开，用本地密码解锁。
3. 从设置查看清理清单。先取消，确认原件仍在；再确认清理，核对新位置和保留的个人文件。
4. 可从设置再次迁移数据文件夹。用新位置中的 Open Sesshuttle 启动，确认文件路径和数据一致。清理旧位置后，退出应用再移除程序及选定文件夹即可卸载本机应用数据。
