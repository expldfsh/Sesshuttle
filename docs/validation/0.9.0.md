# Sesshuttle 0.9.0 Windows 11 x64 免安装版验收

## 交付方式

解压 `sesshuttle-0.9.0-win-x64.zip`，双击 `Sesshuttle.exe`。首次选择数据位置并核对完整路径。选择个人主目录以外的位置时，主目录中可见的 `Sesshuttle Location.json` 保存路径和文件夹标识。设置会显示其位置。

Windows 普通账户读出的交付 ZIP 的 SHA-256 为 `1c135f584021158704e5d266532aa7239b854b69949617c7c485f604d4a85c99`。ZIP 未签名。使用时保留整个解压目录。

## Windows 验收环境

使用 Windows 11 Enterprise Evaluation x64 的独立虚拟磁盘和普通本地测试账户。消息、项目、凭据及模型回复均为合成测试数据，网络只连接本机验收服务。安装包从压缩文件解出后直接运行。AppData 对比覆盖 Roaming、Local、LocalLow，以及账户中额外存在的分支。

首次验证 Codex CLI 0.166.0 时，Windows 在约 34 秒完成样本导入，约 48 秒完成续聊和历史核对。此前的 30 秒上限会在导入中途触发。本版将 Windows 首次验证的等待上限调整为两分钟，保留原有校验和取消操作。

## 首次选择、重开与卸载

程序解压在 C 盘的“文档”，数据选在独立的 D 盘，目录名包含 `Chat 中文 100%`。所有启动均使用普通账户，无需管理员权限。

| 实际操作 | 观察结果 |
| --- | --- |
| 首次打开并取消 Windows 文件夹选择框 | 程序退出，数据目录和主目录位置记录均未创建 |
| 再次打开，选择 D 盘并确认完整路径 | 界面正常显示，数据库出现在 `Chat 中文 100%\Sesshuttle Data\data`，主目录位置记录的标识与数据目录一致 |
| 关闭，再点原来的程序图标 | 直接进入主界面，数据库设备标识相同 |
| 把解压目录搬到 `App 中文 100%` 后双击 | 仍然使用同一份数据库。另一次在窗口尚未载入时关闭，程序正常退出 |
| 退出后，删除解压目录、所选数据目录和可见的位置记录 | Windows 确认三处均已移除 |

在最终 ZIP 的这次测试中，首次运行前、取消后、选定 D 盘后及卸载后的 AppData 清单均有 3,358 项，未遇到不可读路径。卸载后新增 0 项，10 个原有文件发生变化，逐项确认为 Windows 拼写词典、资源管理器图标缓存、用户注册表日志、OneDrive 日志及系统组件的 WebView 缓存。未发现 Sesshuttle 的文件或目录。
