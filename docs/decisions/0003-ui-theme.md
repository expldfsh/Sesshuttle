# 界面主题与选择菜单

按用户确认，当前主题为 Tokyo Night Moon；英文为 Comic Neue，中文为霞鹜文楷。字体随安装包提供，详见 [字体资源](../../assets/font-licenses/README.md)。

所有颜色集中在 `app/shared/themes.ts`，按背景、面板、正文、强调、状态、边框、遮罩和滚动条等语义定义。主进程用同一配置设置窗口背景和原生深浅色模式；渲染器将配置应用到根元素 CSS 变量，弹窗和挂载到 body 的菜单继承同一主题。本机配置保存主题标识，缺失或不认识的标识回退到默认主题。增加新主题时扩展注册表并按相同语义提供颜色，后续再增加用户选择入口，无须逐个修改组件。

`Select.tsx` 负责语言、状态、方向和历史版本选择，替代系统原生 select 展开菜单。使用 combobox/listbox/option 语义，焦点保留在触发器；支持鼠标选择、方向键、Home/End、回车、Esc、Tab、输入首字母和点击外部关闭。键盘高亮与已选值分离，取消不改变值；打开菜单时不会因鼠标原位置改变键盘高亮。

展开层独立挂载，避免被对话列表或详情的滚动区域裁切。它根据可见窗口、触发器和选项内容决定向上或向下展开，限制宽度与高度，必要时内部滚动。主题样式和字体不依赖操作系统弹出菜单。文件选择、系统应用菜单仍由操作系统管理。
