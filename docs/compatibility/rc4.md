# 0.1.0-rc.4 兼容范围

继承 [rc.3](rc3.md) 的存储格式、可恢复删除、版本约束与平台限制。Mac Apple Silicon 包未做 Developer ID 签名、公证；Linux x86_64 包交叉构建，实际运行和真实 R2 往返待用户验收。原有空间、凭据和恢复文件继续使用，不创建新空间。

本轮新增：可逐项确认省略缺失的本地图片，或明确不包含尚未授权的外部图片。只调整导入副本中的图片引用，转成明确缺图说明，并映射数据库分页与分支字节位置。原始备份不改，文字与工具历史保留。

缺少必要历史、父对话、历史损坏、未知资源、不可读取文件和不安全路径仍不能通过此确认绕过。早期格式只有笼统附件错误时，需在源设备重新生成逐文件清单；不擅自猜测缺失内容。

原生验证成功的入口显示“已导入 · 部分附件缺失”，允许继续。再次传输保留缺图说明；这不承诺恢复图片本身或模型对原图细节的记忆。

已在 Mac 验证 Desktop `0.166.0-alpha.5.1` → CLI `0.166.0` → Desktop 的普通及压缩历史接续，并在桌面界面同时导入两个入口。Linux 的原生界面和真实模型/R2 验收仍待进行。[验证记录](../validation/rc4-candidate.md)
