# Sesshuttle 0.2.0 兼容范围

| 平台或能力 | 本版覆盖 |
| --- | --- |
| macOS Apple Silicon | DMG，在 Mac 上从镜像中的应用实际打开并检查。未做 Developer ID 签名及公证。 |
| Linux x86_64 | 针对桌面环境提供解压包及 Debian 包。在独立 Arch x86_64 图形会话以普通用户启动解压包，使用正常的 Electron 保护。Debian 包的内容及架构已核对，本轮未另行在 Debian 桌面安装。 |
| 跨机接续 | Apple Silicon Mac 与 Arch x86_64 之间导入同一对话、续写、回传及继续。通过原生 Codex 内核验证项目归属、历史和实际工作目录。 |
| 目标原生版本 | 已识别 `0.166.0`、`0.166.0-alpha.5.1`、`0.164.0`、`0.164.0-alpha.11.1`。将对话指定到原生项目需要支持项目接口的 0.166.0 系列和本机项目索引，老目标可选仅导入历史。未知目标版本会阻止写入。 |
| 接入已有空间 | 沿用原有加密空间和恢复文件，建议两端均升级到 0.2.0。旧备份只有概括性附件错误时，回到源设备重新生成逐文件清单。 |
| Windows | 尚未进入本次安装及接续验收。 |

**原生项目与侧栏**　能检测到桌面主程序、历史写入成功、原生接口确认属于某项目、以及具体 GPT 软件把对话画在侧栏，是四件可以分别检查的事。空项目通过其已有的原生项目 ID 枚举和关联。若目标没有可验证的项目表，只能显式选择「仅导入本机历史」。自定义历史路径、桌面协议处理程序缺失或多实例可能需要手动打开目标应用。

**数据保护**　扫描当前支持的会话文件、压缩历史和原生索引。索引仍有标题时保留目录项，并标明续聊所需的历史是否可用。导入前保存备份。普通缺图或满足检查条件的不可读临时截图可逐项补图或确认省略；不安全链接、损坏历史及缺必需父历史需要先修复。恢复、删除和版本冲突都有独立确认流程。

**刷新与费用**　打开应用时检查，手动刷新可更新本机及云端清单。上传由选中范围、预览和确认触发。本次新增云端用量是所属同步空间的估算，其他空间、其他设备并发写入和账户账单需在 Cloudflare 查看。
