# Sesshuttle 0.4.0 兼容范围

| 项目 | 支持与限制 |
| --- | --- |
| 安装 | Apple Silicon Mac 使用 DMG。Arch 等 x86_64 Linux 使用 tar.gz，Debian 系可用 amd64 DEB。 |
| 恢复文件 | 两端使用同一格式。新版文件带 R2 地址、Bucket、空间、解密密钥和 Access Key ID。R2 Secret Access Key 由用户在新设备输入。 |
| 旧文件和已有空间 | 沿用原 Bucket、同步空间和密钥。旧文件没有 Access Key ID 时，只匹配本机保存的同地址、同 Bucket、同空间记录。换到全新设备，可在已连接的旧设备上用新版重新导出。 |
| 系统保存凭据 | macOS 使用系统钥匙串。Linux 使用当前图形会话的 Secret Service。系统密码库已解锁时可能直接完成，锁定时由提供程序显示授权窗口。无服务或取消时，可在当前会话同步，并从设置重试保存。 |
| 导入 Codex | 使用与目标历史目录匹配的原生内核和本机工作目录。验证通过的入口可继续，路径、项目绑定和打开方式按本机情况分别显示。 |
| 缺图和缺历史 | 可明确接受软件认定可省略的图片，导入后会保留缺图说明。缺关键历史的对话单独列明原因。在同批清单可确认其余可用对话。 |
