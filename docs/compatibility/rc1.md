# 0.1.0-rc.1 兼容范围

这是 M4 **可安装验收候选版**，尚非 AC01–AC15 全部签核的正式第一版。

## 系统与分发

| 系统 | 提供的包 | 实际验证 |
| --- | --- | --- |
| macOS Apple Silicon | DMG / `.app` | Mac M3、macOS 27.0.1 上运行过安装版，完成隔离界面和内核流程 |
| Linux x86_64 | Debian/Ubuntu `.deb`、通用 `.tar.gz` | 在 Mac 交叉构建，格式/架构可检查；Linux 启动、系统依赖、密钥环、原生入口仍待用户验收 |
| Windows x86_64 | 本轮不交付已验收包 | 后续独立验证 |

Mac 包未做 Developer ID 签名和公证。Linux 的通用压缩包不是 AppImage，不保证任意发行版免依赖运行。`.deb` 的安装菜单与运行结果仍须在真实 Linux 确认。

界面已内置 Comic Neue 与霞鹜文楷及许可证；不要求系统预装字体，离线可显示。当前主题为 Tokyo Night Moon，下拉选项由应用内绘制并继承同一配色。

## Codex 写入适配范围

| 入口内核 | 版本 | Mac 隔离结果 |
| --- | --- | --- |
| Desktop | 0.166.0-alpha.5.1 | 原生读取、迁移、目录绑定、继续与恢复通过 |
| CLI | 0.164.0 | 通过；与 Desktop 完成正式同步引擎 A→B→A 接续 |
| VS Code 扩展 | 0.164.0-alpha.11.1 | 读取、导入、重复导入与恢复通过；研究工具往返通过 |

匹配的是 Codex 可执行文件版本，不是 VS Code 或桌面软件外层版本号。未知版本可只读扫描、显式备份，写入会停止。未来版本不能仅靠修改版本列表视为适配完成。

研究阶段覆盖 Desktop↔Desktop、Desktop↔CLI、Desktop↔IDE 的原生往返。正式安装版走通过 IDE 来源 → 三个共享目标的界面操作，三个目标使用同一已验证内核。独立内核版本另有产品集成测试。**这些证据不代替 Desktop/VS Code 实际原生界面的可见性与继续按钮验收，也不代替 Linux 结果。**

## 内容和使用边界

- 同步完整原始 rollout，不使用摘要代替历史；保留用户消息、助手消息、工具结果、归档标记和可发现的父/子会话依赖。
- 内嵌图片随历史保留，已在原生往返检查。显式本地图片字段可封装 PNG/JPEG/GIF/WebP，单个不超过 8 MiB，须位于源项目或 Codex 目录内；映射仅改变类型明确的资源字段，不替换普通历史文字。外部路径、远端文件 ID、缺失资源或其他未确认格式只允许显式备份。外部图片的原生显示仍需对应样本实机复验。
- 界面预览最近消息，原始同步内容不按预览截断。只读扫描最多 5,000 条记录；预览总文本有内存上限。
- 迁移包最多 200 份关联历史，解压后的 JSON 上限 64 MiB；单个源文件上限 64 MiB。导入前备份总量上限 1 GiB，单个备份文件上限 64 MiB；超限停止，不删除数据以绕过限制。
- 上传前比较一致快照；导入要求退出所有 Codex 进程。软件不会终止日常进程，也不能阻止用户在检查后再次启动其他程序；操作期间保持 Codex 关闭。
- 导入保留源对话身份与来源，使用目标模型配置，并通过只读权限验证。历史路径不会被批量改写；补充的设备与项目说明会进入后续上下文，不自动发送任务。
- Desktop 和 VS Code 自动打开仅支持默认 `~/.codex`。自定义数据目录可导入，但要用已配置该目录的原生入口自行打开。Linux CLI 自动打开需要可用终端。
- 只同步历史及依赖，不同步项目代码、Codex 登录配置或存储凭据。对话中本来存在的文字不会被自动删改，会随历史加密保存。
- 系统密钥服务不可用时连接仅存在内存。恢复文件应由用户另行保管；它不包含 R2 Secret Access Key。
- 第一版使用手动同步，不自动运行后台同步、清理云端版本或删除旧备份。当前历史版本列表保留所有已发布版本。

## 状态含义

| 显示 | 含义 |
| --- | --- |
| 已同步 | 本机扫描内容与当前云端版本一致；不代表每个入口都已经导入 |
| 已备份 | 版本已加密上传并发布 |
| 内核已验证 | 原生内核能读取导入历史、目标目录与权限检查通过；仍需实际原生界面验收 |
| 已导入待验证 / 已恢复待验证 | 内容已变更，暂不开放自动继续 |
| 部分完成 | 部分目标成功，其他目标失败或未配置；逐目标结果是最终依据 |
| 两边均有修改 | 发现分歧；不自动覆盖，需要明确选版本 |

真实 R2、Linux、完整来源×目标矩阵与系统凭据服务尚待集中验收，见[验收步骤](../guides/zh-CN/linux-acceptance.md)。
