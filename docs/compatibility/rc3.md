# 0.1.0-rc.3 兼容范围

安装验收候选版，面向 Mac Apple Silicon 和 Linux x86_64。Linux 包在 Mac 交叉构建，Linux 实机及真实 R2 的验收仍待用户完成。Mac 包未做 Developer ID 签名和公证。Windows 未在本轮验收。

沿用 [rc.2 的历史格式、分块容量、加密及版本约束](rc2.md)。原有 R2 空间和恢复文件继续使用，两台设备均建议更新为 rc.3。rc.1 不能读取分块格式。

- 修复压缩流提前关闭导致的主进程 AbortError；真实历史只读扫描通过。
- 原生项目名来自只读项目目录和原生关联；同目录旧项目与带明确桌面绑定的项目按绑定识别。无法唯一确认时显示歧义，不编造归属。
- 预览逐条显示选中的会话、必需的父/分支历史，以及显式勾选的后台子会话。后台记录默认不包含；旧云端备份本来包含的记录会如实列出。
- 现存的外部图片附件需要本次逐文件授权，真正缺失、不可读取、链接和不支持格式分开显示。仅捕获显式图片字段，历史正文中任意提及的文件不会被扫描上传。
- 原始加密备份保持不变；导入副本中的附件路径及对应分页/分支字节位置一起映射，防止路径改变破坏原生读取。
- 本机可恢复删除会保留完整恢复内容。共享附件、项目文件、R2/其他设备记录保留；原生数据库保留共享页和空闲页，不通过压缩数据库强行腾空间。暂无永久清空回收站功能。
- 删除前须关闭 Codex；未完成的删除阻止后续导入。恢复只处理删除记录，同名新内容会阻止恢复，不覆盖后来修改。
- 删除只对当前配置的扫描位置中能完整识别的记录执行；不同数据目录分开操作。专用图片附件可回收，项目文件、未知归属附件及链接保留并显示原因。
- 仍为手动刷新；不自动监听或上传。同步及删除均需预览和明确确认。

目标运行时：Desktop `0.166.0-alpha.5.1`、CLI `0.166.0`，保留 CLI `0.164.0` / VS Code `0.164.0-alpha.11.1` 适配。未知版本、缺失前置历史、数据库结构不兼容或附件不完整时，不会强行标记为可接续。

真实历史副本已在 Mac 的 Desktop/CLI 内核通过原生分页和本机模拟模型接续；这不代替 Linux 原生界面或真实模型/R2 的验收。[本轮证据](../validation/rc3-candidate.md)
