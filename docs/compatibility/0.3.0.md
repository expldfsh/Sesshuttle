# 0.3.0 兼容与数据边界

对话来源、原生项目、跨设备接续和内核版本沿用 [0.2.0 的兼容范围](0.2.0.md)。本轮交付 Apple Silicon 的 DMG、x86_64 Linux 的 tar.gz 和 amd64 的 DEB。Mac 包未做 Developer ID 签名与公证。

- **已有 R2 空间**　原有版本、分块和恢复文件继续使用。已有空间在首次确认云端删除操作时升级元数据格式。使用这一空间的设备需先升级至 0.3.0 并结束旧客户端的写入。旧版无法打开升级后的空间。
- **本机范围**　按已配置的 Codex 历史位置核对，包括多个入口共用的目录。已知共用、项目源文件及无法确认独占的附件保留。回收和恢复均写在操作发起的电脑。永久删除清单按应用可管理的文件和记录计算，整库安全备份、系统快照及手工备份各自保留。
- **云端范围**　精确处理当前空间中选定的版本及对象。其他备份中嵌入的会话、回收站引用及未选版本保护对应内容。即使版本清单对象本身被其他回收记录引用，也会保留该对象。
- **断线与并发**　使用条件写入和加密的待处理清单。预览后出现改动需要重新确认。写入设备意外退出时可在原安装上重试；系统不会按时钟强行抢占可能还活跃的写入者。若该设备和其应用数据永久丢失且空间仍有占用标记，本版没有跨设备强制解锁入口。
- **其他设备**　刷新可见云端版本变化。已经导入的历史、项目目录和附件由各设备本地管理。再次备份或导入均由用户发起。
